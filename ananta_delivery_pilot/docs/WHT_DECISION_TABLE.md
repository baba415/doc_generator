# WHT Decision Table (Operational)

| Condition | Default Position | Evidence Required |
|---|---|---|
| Goods invoice by non-producer entity | WHT applicable (2% baseline in ruleset) | Invoice + buyer deduction record |
| Producer/processing pilot position asserted | WHT not applied only with approved evidence | Processing agreement ref, allocation note, run/batch IDs, COA linkage |
| Murabaha supplier-direct funding flow | Handle per funder-approved tax treatment for financing leg | PFI to bank, bank purchase proof, Murabaha schedule |
| Any uncertainty | Escalate to finance/tax reviewer | Written signoff + override reason |

> This table is operational guidance. Confirm legal positions with current regulations and tax counsel.
